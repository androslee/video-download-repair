# Changelog

## Unreleased

- Shuffler can discover video files in folders and subfolders, with repeatable
  exclusions and a dry-run preview of the sources selected.
- Added readable source timeline reports, source selection and resolution details,
  optional shuffler answer-key mapping and render progress.
- Added deliberately omitted pieces for testing disconnected video coverage.
- Prepared public-repository documentation and Linux CI workflows; hosted CI and
  desktop installation still require verification.

## 0.1.1 — local prototype

- Added a reproducible shuffler for clean or overlapping fragments and aligned
  resolution variants, with separate truth manifests and randomized inputs.
- Added recursive fragment discovery and a Blender subfolder option.

## 0.1.0 — local prototype

- Added local picture/audio overlap matching, relative timeline reports, a
  conservative FFmpeg renderer, and a separate Blender sequencer adapter.
